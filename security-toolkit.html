Employee Security Toolkit

Simple, free tools to help you spot, check and stay safer online.

These are free, publicly available tools you can use for basic self-checks on suspicious emails, links, files and passwords. They're not a replacement for IT — just a quick way to get peace of mind.

Be alert.
Stay safe.
⚠️
Never paste passwords, internal documents, or confidential files into these public tools — some make submissions visible to their security community. Use them only for things that are fine to be semi-public (e.g., a suspicious link), and when in doubt, contact IT/Security.
